# ДЗ 01

## Запуск

```bash
cmake -S . -B build
cmake --build build -j
ctest --test-dir build --output-on-failure   # correctness tests
./build/bench/hw01_bench                     # load tests
```

## Архитектура

Для удобства сделаны `Array<T>` (хранит aligned массив), `IKernels<T>` (интерфейс для Scalar/SIMD реализаций), `IExecutor` (обёртка для параллелизации) и `Engine<T>` (объединяет всё в одну сигнатуру).

Matmul: порядок циклов i-k-j (внутренний цикл идёт по строкам B и C, для coalesced паттерна доступа),
в SIMD-версии внутренний цикл обрабатывает по одному вектору строки C. Параллелизация — по
строкам результата.

### Анализ

- **add / sub / mul / div** — memory bound: SIMD помогает слабо, основной прирост дают потоки
  (до 8, дальше упираемся в пропускную способность памяти).
- **sum / mean** — memory bound, но данные помещаются в L3 и нет записи результата, поэтому это
  самые быстрые операции; заметный прирост дают и SIMD, и потоки.
- **silu / gelu** — compute bound: наибольший прирост даёт SIMD (особенно для GELU).
- **matmul** — compute bound: лучше всего масштабируется, SIMD и потоки дают прирост почти
  независимо.
