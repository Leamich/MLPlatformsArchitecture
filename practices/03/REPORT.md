# Отчет по практике

## Функции активации

* Сигмоида не хотела векторизовываться, только из-под флагов `-ffast-math`
* В остальном после этого всё заработало как ожидалось, `sigmoid_data_dependent` не векторизуется, т.к. данные зависимы (с ифом тоже).
* причем автовекторизация работает (незначимо) лучше, чем своя SIMD-реализация
* с ReLU та же история

## MulAdd

Тут выигрыш очень небольшой есть на размерах 1024, 4096, а на 1M и 3M его либо нет, либо хуже. Без стандартной векторизации baseline решение работает где-то вдвое хуже.

При реализации с TBB метрики ухудшаются (может маловат размер, чтобы он не помещался в L1).
